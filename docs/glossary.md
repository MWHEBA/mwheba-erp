# MWHEBA ERP — System Glossary & Terminology (قاموس المصطلحات والمفاهيم الموحدة)

> **قاموس المصطلحات الفنية والمعمارية والمالية والصناعية المعتمدة** في نظام **MWHEBA ERP** لتوحيد المفاهيم بين فرق التطوير، المحاسبين، ومسؤولي التشغيل.

---

## 1. المصطلحات المحاسبية والمالية (Financial & Accounting)

| المصطلح | المصطلح المقابل بالإنجليزية | المفهوم والتعريف داخل النظام |
|---|---|---|
| **القيد المزدوج** | Double-Entry Bookkeeping | قاعدة تسجيل المعاملات المالية بحيث يتساوى مجموع المدين مع مجموع الدائن في كل حركة ($\sum \text{Debit} = \sum \text{Credit}$). |
| **شجرة الحسابات** | Chart of Accounts (COA) | الهيكل الهرمي لحسابات المنشأة (5 مستويات) الموزعة على الأصول، الالتزامات، حقوق الملكية، الإيرادات، والمصروفات. |
| **محرك تقييم العملات** | FX Revaluation Engine | موديول آلي يعيد تقييم البنود النقدية المفتوحة بالعملات الأجنبية وفق أحدث أسعار الصرف بنهاية الفترة المالية واحتساب الأرباح/الخسائر غير المحققة. |
| **الأرباح والخسائر المحققة** | Realized FX Gain/Loss | الفروق النقدية الفعلية الناتجة عن سداد أو تحصيل فواتير بعملة أجنبية بسعر صرف يختلف عن سعر الصرف وقت إنشاء الفاتورة. |
| **فروق السنتات والتقريب** | Penny Differences | الفروق الحسابية الطفيفة ($\le 0.05$) الناتجة عن تقريب الكسور العشرية متعددة العملات، ويتم ترحيلها آلياً لحساب تسوية مخصص. |
| **حارس عمر سعر الصرف** | Rate Age Guard | قاعدة أمان تمنع ترحيل تقييم العملات إذا كان سعر الصرف مسجلاً منذ أكثر من 7 أيام دون اعتماد رسمي من المدير المالي. |
| **بوابة المحاسبة** | Accounting Gateway | البوابة البرمجية الموحدة المسؤولة عن إنشاء وترحيل القيود اليومية في قاعدة البيانات لمنع التجاوزات اليدوية. |
| **إغلاق الفترة المالية** | Period Closing | قفل العمليات المحاسبية لتاريخ محدد مع منع التعديل وإجراء تقييم العملات وتثبيت الأرصدة. |
| **القيد العكسي** | Reversal Entry | قيد محاسبي يتم توليده آلياً عند إلغاء عملية أو إعادة فتح فترة مالية للحفاظ على سجل المراجعة (Audit Trail). |
| **العهدة النقدية** | Employee Custody / Petty Cash | مبلغ مالي يسلم للموظف لتغطية نفقات تشغيلية مؤقتة ويخضع للتسوية والتصفية الفواتيرية. |

## 2. مصطلحات تسعير المطبوعات والإنتاج (Printing & Industrial Operations)

| المصطلح | المصطلح المقابل بالإنجليزية | المفهوم والتعريف داخل النظام |
|---|---|---|
| **محرك الـ SSOT** | Single Source of Truth Engine | محرك التسعير المركزي الذي تمر عبره كل عمليات حساب التكاليف لضمان تطابق النتائج عبر المنظومة. |
| **المونتاج وتوزيع المقاسات** | Imposition | الحسابات الهندسية لتوزيع مقاس المنتج النهائي المفتوح على فرخ الورق الخام لتحقيق أقصى استغلال. |
| **عدد النسخ في الفرخ** | Ups per Sheet | عدد المنتجات المستخرجة من فرخ الورق الواحد بناءً على الأبعاد وهامش البنسة والتكعيب. |
| **فرخ الورق الخام** | Raw Paper Sheet | المقاس القياسي للورق الوارد من الموردين قبل التقطيع (مثل: $70\times100$ سم، $66\times88$ سم). |
| **الجراماج** | Grammage (GSM) | وزن المتر المربع من الورق بالجرام ($g/m^2$)، ويستخدم في حساب وزن الورق الإجمالي بالكيلوجرام. |
| **هالك التظبيط والتشغيل** | Waste & Makeready | كمية الورق المهدورة أثناء ضبط الماكينة (زنكات، ألوان، سلوفان) ونسبة الهالك الميكانيكي أثناء السحب. |
| **الزنكات الطباعية** | CTP Plates | الألواح المعدنية المعالجة بالليزر المستخدمة لنقل التصميم والألوان في ماكينات الأوفست. |
| **السلوفان والتشطيب** | Lamination & Finishing | طبقات الحماية السطحية (مط، لامع، مخملي Thermal) والعمليات اللاحقة (بصمة، UV، تكسير، ريجة). |
| **أمر الشغل** | Work Order | وثيقة التشغيل وصالة الإنتاج التي تمثل مركز تكلفة ومهمة تصنيع مستقلة بدون إظهار هوامش أرباح الشركة للعمال. |
| **جسر المشتريات** | Procurement Bridge | الخدمة الآلية التي تفحص خامات أمر الشغل وتولد أوامر شراء للخامات الناقصة وخدمات الورش الخارجية. |

## 3. مصطلحات المخازن والمبيعات والمشتريات (Master Data & Commercial)

| المصطلح | المفهوم والتعريف داخل النظام |
|---|---|
| **المخزن (Warehouse)** | **المصطلح المعتمد حصراً** في النظام (ممنوع استخدام لفظ مستودع) لأي موقع تخزين لخامات الورق أو المنتجات. |
| **حركة المخزن (Stock Movement)** | سجل حركة الصرف أو الإضافة أو التحويل مع توثيق المصدر والتاريخ والمسؤول. |
| **عرض السعر (Quotation)** | وثيقة تجارية موجهة للعميل تتضمن المواصفات والأسعار وصلاحية العرض مع حجز مبدئي للطاقة الإنتاجية. |
| **حد الائتمان (Credit Limit)** | الحد الأقصى للمديونية المسموح بها للعميل قبل إيقاف إصدار فواتير بيع آجلة جديدة. |
| **قوائم الأسعار (Price Lists)** | شرائح تسعير مخصصة (جملة، قطاعي، VIP) مع نسب خصم تلقائية بناءً على تصنيف العميل والكميات. |
| **إذن الاستلام (GRN - Goods Receipt Note)** | إثبات استلام خامات الورق أو البضائع وفحصها مخزنياً ومطابقتها بأمر الشراء. |

## 4. المصطلحات الأمنية والبرمجية (RBAC & Platform Architecture)

| المصطلح | المفهوم والتعريف داخل النظام |
|---|---|
| **الأدوار الـ 10 القياسية** | منظومة الأدوار المؤسسية المعتمدة (Admin, Financial Manager, Accountant, Sales Manager, Sales Rep, Procurement, Inventory Manager, Production, HR, Viewer). |
| **محرك كاش الصلاحيات $O(1)$** | كاش داخلي في الذاكرة على مستوى الـ Request (`RolePermissionBackend`) يمنع استعلامات الداتابيز المتكررة عند فحص صلاحيات المستخدم. |
| **نطاق رؤية البيانات (Visibility Scope)** | قواعد عزل السجلات (شامل لكافة المؤسسة / مقتصر على فرع ومخزن المستخدم / مقتصر على السجلات التي أنشأها المندوب فقط). |
| **سجل التدقيق غير القابل للتعديل (AuditTrail)** | سجل أمني يوثق كل إضافة أو تعديل أو حذف مع حفظ القيمة القديمة والجديدة ومعرف المستخدم والـ IP. |
| **مانع التكرار (Idempotency Key)** | مفتاح أمان فريد يمنع تكرار تنفيذ نفس العملية المالية أو التحصيل في حال الضغط المزدوج أو مشاكل الشبكة. |
| **ترقيم الصفحات الخادمي (SSR Pagination)** | تقنية تحميل صفحات الجداول من السيرفر بسرعة فائقة مع مزامنة الرابط عبر `history.replaceState`. |
